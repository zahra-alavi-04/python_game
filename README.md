# python_game
A simple number guessing game written in python 

# بازی حدس عدد با پایتون (Python Guessing Game)

این یک بازی متنی ساده و جذاب است که با زبان برنامه‌نویسی **پایتون** نوشته شده است. 

## 📝 توضیحات بازی
در این بازی، کامپیوتر یک عدد تصادفی بین ۱ تا ۱۰۰ در نظر می‌گیرد. بازیکن باید با دریافت راهنمایی (برو بالاتر / برو پایین‌تر) این عدد را حدس بزند. بازیکن برای بردن بازی فقط **۸ حدس** دارد!

## 🚀 نحوه اجرا
برای اجرای این بازی، مراحل زیر را دنبال کنید:
1. پایتون را روی سیستم خود نصب داشته باشید.
2. فایل `game.py` را دانلود کنید.
3. فایل را در محیط پایتون (یا ترمینال با دستور `python game.py`) اجرا کنید.

## 🛠 تکنولوژی‌های استفاده شده
* Python 3
* کتابخانه استاندارد `random`
